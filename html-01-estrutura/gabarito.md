# HTML: a estrutura de uma página — Gabarito

> Entregar só depois da correção. Todas as soluções foram testadas no playground. Aqui está só o `<body>`; o esqueleto (doctype, html, head, body) é o mesmo de sempre.

## 01 — Primeiro título
```html
<h1>Meu site</h1>
<p>Feito na Greenn School</p>
```

## 02 — Título da aba
```html
<h1>Ana Souza</h1>
```

```html
<!-- head -->
<meta charset="UTF-8">
<title>Portfólio da Ana</title>
```

## 03 — Hierarquia de títulos
```html
<h1>Receita de bolo</h1>
<h2>Ingredientes</h2>
<h2>Preparo</h2>
<h3>Massa</h3>
```

## 04 — Endereço com quebras
```html
<h2>Onde estamos</h2>
<p>Av. Brasil, 500<br>Boa Viagem<br>Recife - PE</p>
```

## 05 — Destaques no texto
```html
<p>A prova é <strong>sexta</strong> às <em>8h</em>. <mark>Não esqueça!</mark>
</p>
```

## 06 — Mostrando tags como texto
```html
<p>Para um título use &lt;h1&gt;</p>
<p>Greenn &amp; Kore</p>
```

## 07 — Fechando as tags
```html
<h1>Aula de HTML</h1>
<p>Hoje vamos <strong>fechar tags.</strong>
</p>
<p>Agora <em>entendi.</em>
</p>
```

## 08 — Desafio: página pessoal
