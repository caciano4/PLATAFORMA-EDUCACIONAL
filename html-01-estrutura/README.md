# HTML: a estrutura de uma página

**Módulo:** HTML · aula 1 de 4
**Playground dos alunos:** https://site-alunos-nu.vercel.app/html-01/
**Apostila:** `apostila-html-01.pdf` (também para download no site)
**Duração:** 2h

O playground de HTML é diferente dos de JavaScript: o aluno escreve o **HTML** de um lado e vê a **página renderizada** do outro. A verificação aponta tags sem fechar ou fora de ordem, e os exercícios são corrigidos lendo a página montada (tags, textos e atributos).

## Exercícios

| # | Exercício | Objetivo |
|---|---|---|
| 01 | Primeiro título | Criar uma página com um título e um parágrafo. |
| 02 | Título da aba | Dar um título para a aba do navegador. |
| 03 | Hierarquia de títulos | Montar a estrutura de um artigo com três níveis de título. |
| 04 | Endereço com quebras | Escrever um endereço em três linhas dentro de um único parágrafo. |
| 05 | Destaques no texto | Marcar partes de um parágrafo com strong, em e mark. |
| 06 | Mostrando tags como texto | Explicar HTML dentro de uma página HTML, sem o navegador interpretar as tags. |
| 07 | Fechando as tags | Consertar um HTML com tags fora de ordem e sem fechar. |
| 08 | Desafio: página pessoal | Montar uma mini página pessoal com tudo o que aprendemos. |
