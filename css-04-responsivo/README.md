# CSS: responsivo, transições e o site completo

**Módulo:** CSS · aula 4 de 4
**Playground dos alunos:** https://site-alunos-nu.vercel.app/css-04/
**Apostila:** `apostila-css-04.pdf` (também para download no site)
**Duração:** 2h

No playground de CSS o aluno edita o **style.css** de um lado, vê o **index.html** (só leitura) logo abaixo e a **página renderizada** do outro. A verificação aponta chaves sem fechar, declarações sem `:` ou sem `;`, e os exercícios são corrigidos lendo o estilo computado da página (cores, tamanhos, display, posição) e, para hover e media queries, o próprio texto do CSS.

## Exercícios

| # | Exercício | Objetivo |
|---|---|---|
| 01 | Tamanhos em rem e % | Usar unidades relativas. |
| 02 | Muda de cor no celular | Escrever sua primeira media query. |
| 03 | Colunas que empilham | Fazer um layout de colunas virar pilha no celular. |
| 04 | Mobile first | Começar pelo celular e adicionar colunas nas telas grandes. |
| 05 | Botão com transição | Dar resposta suave ao hover. |
| 06 | Selo no canto do cartão | Posicionar um elemento em relação ao pai. |
| 07 | Tema com variáveis | Centralizar as cores do site em variáveis. |
| 08 | O site responsivo | Juntar tudo: container, header flex, cards em grid, hover e media query. |
