# LARAVEL 1 — PHP: O BÁSICO

**Módulo:** Laravel · aula 1 de 6
**Playground dos alunos:** https://site-alunos-nu.vercel.app/php-01/
**Apostila:** `apostila-php-01.pdf` (também para download no site)
**Duração:** 2h30

O playground de PHP roda um **PHP 8.4 de verdade no navegador** (php-wasm, carregado uma vez, ~12 MB) dentro de um Web Worker: o aluno escreve o `script.php`, clica em ▶ Executar e vê a saída, com erros do PHP traduzidos em dicas. O botão "ver como página" mostra a saída renderizada como HTML (preparação para o Blade). Exercícios são corrigidos comparando a saída com a esperada (igual às aulas de JavaScript).
