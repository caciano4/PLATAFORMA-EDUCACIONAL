# CSS: box model, margin, padding e border

**Módulo:** CSS · aula 2 de 4
**Playground dos alunos:** https://site-alunos-nu.vercel.app/css-02/
**Apostila:** `apostila-css-02.pdf` (também para download no site)
**Duração:** 2h

No playground de CSS o aluno edita o **style.css** de um lado, vê o **index.html** (só leitura) logo abaixo e a **página renderizada** do outro. A verificação aponta chaves sem fechar, declarações sem `:` ou sem `;`, e os exercícios são corrigidos lendo o estilo computado da página (cores, tamanhos, display, posição) e, para hover e media queries, o próprio texto do CSS.

## Exercícios

| # | Exercício | Objetivo |
|---|---|---|
| 01 | Uma caixa colorida | Dar tamanho e cor a um div vazio. |
| 02 | Respiro por dentro | Usar padding para o texto não grudar na borda. |
| 03 | Borda e cantos | Desenhar a borda de um cartão e arredondar os cantos. |
| 04 | Espaço entre os itens | Separar caixas com margin. |
| 05 | Conteúdo centralizado | Montar o container clássico de um site. |
| 06 | Link que vira botão | Usar inline-block para dar tamanho a um link. |
| 07 | Escondendo o rascunho | Tirar um elemento da página com display: none. |
| 08 | Cartão de produto | Juntar tudo num cartão de produto bonito. |
