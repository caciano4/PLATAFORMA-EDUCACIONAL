# AULA 1 — VARIÁVEIS, OBJETOS E MÉTODOS DE ARRAY

**Duração sugerida:** 2h30
**Playground dos alunos:** https://site-alunos-nu.vercel.app/aula-01/
**Apostila:** `apostila-aula-01.pdf` (também para download no site)

## Objetivos da aula

1. Explicar o que é uma variável e escolher entre `let` e `const`.
2. Conhecer os tipos de dados e usar `typeof`.
3. Criar objetos, ler, alterar e remover propriedades e criar métodos.
4. Trabalhar com arrays de objetos (a forma como os dados chegam de verdade).
5. Usar `map`, `filter`, `find`, `some`, `every` e `reduce`.
6. Usar desestruturação, spread, JSON, `?.` e `??`.
