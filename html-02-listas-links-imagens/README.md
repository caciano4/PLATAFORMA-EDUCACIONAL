# HTML: listas, links e imagens

**Módulo:** HTML · aula 2 de 4
**Playground dos alunos:** https://site-alunos-nu.vercel.app/html-02/
**Apostila:** `apostila-html-02.pdf` (também para download no site)
**Duração:** 2h

O playground de HTML é diferente dos de JavaScript: o aluno escreve o **HTML** de um lado e vê a **página renderizada** do outro. A verificação aponta tags sem fechar ou fora de ordem, e os exercícios são corrigidos lendo a página montada (tags, textos e atributos).

## Exercícios

| # | Exercício | Objetivo |
|---|---|---|
| 01 | Lista de compras | Criar uma lista com marcadores com três itens. |
| 02 | Passo a passo | Criar uma lista numerada começando do 1. |
| 03 | Menu com submenu | Montar um menu em lista com um sub-item. |
| 04 | Link externo | Criar um link que abre o site do MDN em nova aba. |
| 05 | Sumário com links internos | Fazer links que rolam até seções da mesma página. |
| 06 | Imagem com alt | Mostrar o logo com texto alternativo e largura definida. |
| 07 | Imagem que é link | Fazer o logo levar ao site ao ser clicado. |
| 08 | Desafio: página de receita | Juntar lista, links e figura numa página completa. |
