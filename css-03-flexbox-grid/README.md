# CSS: Flexbox e Grid

**Módulo:** CSS · aula 3 de 4
**Playground dos alunos:** https://site-alunos-nu.vercel.app/css-03/
**Apostila:** `apostila-css-03.pdf` (também para download no site)
**Duração:** 2h

No playground de CSS o aluno edita o **style.css** de um lado, vê o **index.html** (só leitura) logo abaixo e a **página renderizada** do outro. A verificação aponta chaves sem fechar, declarações sem `:` ou sem `;`, e os exercícios são corrigidos lendo o estilo computado da página (cores, tamanhos, display, posição) e, para hover e media queries, o próprio texto do CSS.

## Exemplos

| # | Exemplo | Bloco |
|---|---|---|
| 01 | display: flex: os filhos entram em linha | Flexbox |
| 02 | justify-content: distribuindo na horizontal | Flexbox |
| 03 | align-items: alinhando na vertical | Flexbox |
| 04 | flex-direction e flex-wrap | Flexbox |
| 05 | flex: 1: quem cresce para preencher | Flexbox |
| 06 | O cabeçalho com menu | Flexbox |
| 07 | Centralizar qualquer coisa | Flexbox |
| 08 | display: grid: linhas e colunas | Grid |
| 09 | Layout de página com áreas | Grid |
| 10 | Galeria que se adapta sozinha | Grid |
| 11 | Área livre | Livre |

## Exercícios

| # | Exercício | Objetivo |
|---|---|---|
| 01 | Três caixas em linha | Colocar os filhos lado a lado com flex. |
| 02 | Um em cada ponta | Distribuir os itens com justify-content. |
| 03 | No centro de tudo | Centralizar um elemento na horizontal e na vertical. |
| 04 | Menu fixo, conteúdo que cresce | Usar flex: 1 para o conteúdo ocupar o resto. |
| 05 | Cabeçalho com menu | Montar o header clássico: logo de um lado, menu do outro. |
| 06 | Grade de três colunas | Criar uma grade com grid. |
| 07 | Galeria que se adapta | Usar auto-fit e minmax para a grade se ajustar sozinha. |
| 08 | Página inteira com grid | Montar header, menu lateral, conteúdo e rodapé com áreas. |

O gabarito está em `gabarito.md`.
