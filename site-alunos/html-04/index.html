Um site feito só de <div> funciona, mas ninguém sabe o que é cada parte: nem o Google, nem o leitor de tela, nem o colega que vai dar manutenção. As tags semânticas dizem o papel de cada bloco. Visualmente são iguais a uma div; a diferença é o significado.

  
Experimente: compare os dois blocos na prévia: idênticos. A diferença está no código.







  
<header>: topo (logo, título). <nav>: o menu de navegação. <main>: o conteúdo principal (só um por página). <footer>: rodapé. É o esqueleto de quase todo site.

  
Experimente: coloque o nav dentro do header.







  
<section>: uma seção com tema próprio (geralmente com título). <article>: conteúdo que faz sentido sozinho (um post, uma notícia, um produto). <aside>: conteúdo lateral/relacionado (uma caixa "veja também").

  
Experimente: adicione um segundo article dentro da section.







  
id identifica um elemento (único na página); class marca um grupo (vários elementos podem ter a mesma, e um elemento pode ter várias, separadas por espaço). É por eles que o CSS e o JavaScript encontram as coisas.

  
Experimente: dê a classe destaque para o segundo card também.







  
<meta name="viewport"> faz a página se ajustar ao celular (sem ele, o site aparece minúsculo). <meta name="description"> é o texto que o Google mostra no resultado. <link rel="icon"> é o ícone da aba.

  
Experimente: mude a description. Ela não aparece na página, mas o Google lê.







  
<video> e <audio> tocam mídia sem plugin. controls mostra os botões, autoplay e loop fazem o que o nome diz. Dentro, um texto de fallback para navegadores antigos.

  
Experimente: adicione loop ao vídeo.







  
<iframe> embute outra página: um mapa, um vídeo do YouTube, um formulário externo. É assim que a prévia deste playground funciona!

  
Experimente: troque o src por https://www.openstreetmap.org/export/embed.html.







  
Juntando tudo: head completo, header com nav, main com section e articles, aside e footer. Repare que, mesmo sem CSS, a estrutura já faz sentido ao ler.

  
Experimente: adicione um terceiro article com uma imagem.







  
O esqueleto semântico para testar.

  
Dica: só um <main> por página.







  
🎯 Objetivo: Montar a estrutura básica de um site com as tags certas.
O que fazer
  1. <header> com um <h1> Meu site.
  2. <main> com um parágrafo.
  3. <footer> com © 2026.
Resultado esperado
Topo, conteúdo e rodapé, cada um na tag certa

  
Depois de acertar, teste também: Adicione um <nav> dentro do header.








  
🎯 Objetivo: Criar o menu dentro de nav, como lista de links.
O que fazer
  1. Um <nav> com uma <ul>.
  2. Três <li>, cada um com um <a>: Início (#), Sobre (#sobre) e Contato (#contato).
Resultado esperado
Lista de 3 links dentro do nav

  
Depois de acertar, teste também: Coloque o nav dentro do header.








  
🎯 Objetivo: Organizar notícias em section e article.
O que fazer
  1. Dentro do <main>, uma <section> com um <h2> Notícias.
  2. Dentro dela, dois <article>, cada um com um <h3> e um <p>.
Resultado esperado
Section "Notícias" com 2 artigos

  
Depois de acertar, teste também: Adicione um <aside> ao lado da section.








  
🎯 Objetivo: Marcar elementos para o CSS e o JavaScript encontrarem.
O que fazer
  1. Um <h1> com id="titulo".
  2. Três <div> com class="card"; o primeiro também com a classe destaque.
Resultado esperado
h1#titulo e 3 .card (o 1º também .destaque)

  
Depois de acertar, teste também: Dê um id diferente para cada card.








  
🎯 Objetivo: Preparar o head para celular e para o Google.
O que fazer
  1. <meta charset="UTF-8">.
  2. <meta name="viewport" content="width=device-width, initial-scale=1">.
  3. <meta name="description" content="..."> com qualquer texto.
  4. <title> Portfólio.
Resultado esperado
Head com charset, viewport, description e title

  
Depois de acertar, teste também: Adicione o ícone da aba com <link rel="icon">.








  
🎯 Objetivo: Embutir um vídeo com botões de play.
O que fazer
  1. Uma <video> com src="https://www.w3schools.com/html/mov_bbb.mp4".
  2. Os atributos controls e width="320".
  3. Um texto de fallback dentro da tag.
Resultado esperado
Player de vídeo de 320px com controles

  
Depois de acertar, teste também: Adicione muted autoplay.








  
🎯 Objetivo: Colocar um mapa na página com iframe.
O que fazer
  1. Um <iframe> com src="https://www.openstreetmap.org/export/embed.html".
  2. width="400" e height="250".
  3. Um title="Mapa" (acessibilidade).
Resultado esperado
Mapa de 400×250 dentro da página

  
Depois de acertar, teste também: Troque o src por um vídeo do YouTube (botão Compartilhar → Incorporar).








  
🎯 Objetivo: Montar uma página inteira com tudo do módulo de HTML.
O que fazer
  1. Head com charset, viewport e title.
  2. <header> com a <img> do logo (com alt), um <h1> e um <nav> com uma <ul> de 2+ links.
  3. <main> com uma <section id="cursos"> contendo um <h2> e 2+ <article class="card"> com <h3>.
  4. Na section, uma <table> de horários com <th>.
  5. Um <form> de contato com input de e-mail required e botão submit.
  6. <footer> com o ano.
Resultado esperado
Um site de verdade: cabeçalho com menu, cursos em cards, tabela, formulário e rodapé

  
Depois de acertar, teste também: Mostre para alguém e peça para achar cada parte só lendo o código.
