O projeto: o portfólio que você estruturou (HTML) e estilizou (CSS) ganha agora comportamento: ano automático no rodapé, botão de tema escuro, lista de projetos gerada a partir de um array de objetos e formulário que valida e responde. Tudo com o que você viu nas aulas de DOM, formulários, objetos e arrays.


Como funciona: três abas (index.html, style.css, script.js); a prévia é o site de verdade e o checklist testa o site (clica no botão, envia o formulário) quando você clica em ▶ Atualizar. Se você fez os projetos anteriores neste navegador, seus arquivos já estão nas abas.

O primeiro JavaScript útil: nunca mais atualizar o ano do rodapé na mão.


const ano = new Date().getFullYear();
document.querySelector("#ano").textContent = ano;


new Date() é a data de agora; getFullYear() devolve o ano como número. Selecionar e trocar o texto é o que você fez na aula de DOM.








  
O botão #tema liga e desliga a classe escuro no body; o CSS faz o resto. É o classList.toggle da aula de DOM.


// script.js
const botaoTema = document.querySelector("#tema");
botaoTema.addEventListener("click", () => {
  document.body.classList.toggle("escuro");
  const ativo = document.body.classList.contains("escuro");
  botaoTema.textContent = ativo ? "☀️ Tema claro" : "🌙 Tema escuro";
});


/* style.css: redefina as variáveis quando o body tiver a classe */
body.escuro {
  --fundo: #15171E;
  --texto: #E2E8F0;
  background-color: var(--fundo);
  color: var(--texto);
}
body.escuro article { background-color: #1F2330; }










  
Os projetos viram dados: um array de objetos no script.js. Um laço (forEach ou map) cria um <article> para cada um dentro de #lista-projetos. Para adicionar um projeto, você só acrescenta um objeto no array.


const projetos = [
  { nome: "Site da escola", descricao: "HTML semântico e CSS responsivo.", link: "https://github.com" },
  { nome: "Lista de tarefas", descricao: "App com JavaScript e DOM.", link: "https://github.com" },
];

const lista = document.querySelector("#lista-projetos");
projetos.forEach((p) => {
  const card = document.createElement("article");
  card.className = "card";
  card.innerHTML = `<h3>${p.nome}</h3><p>${p.descricao}</p><a href="${p.link}" target="_blank">Ver projeto</a>`;
  lista.appendChild(card);
});










  
No submit: preventDefault(), ler os campos, validar (nome com 2+ letras, e-mail com @, mensagem não vazia), mostrar o erro em #mensagem ou, se estiver tudo certo, agradecer pelo nome e limpar o formulário.


const form = document.querySelector("#form-contato");
const mensagem = document.querySelector("#mensagem");

form.addEventListener("submit", (evento) => {
  evento.preventDefault();
  const nome = form.nome.value.trim();
  const email = form.email.value.trim();
  const texto = form.mensagem.value.trim();

  if (nome.length < 2) { mensagem.textContent = "Digite seu nome."; return; }
  if (!email.includes("@")) { mensagem.textContent = "Digite um e-mail válido."; return; }
  if (!texto) { mensagem.textContent = "Escreva uma mensagem."; return; }

  mensagem.textContent = `Obrigada, ${nome}! Recebi sua mensagem e respondo em breve.`;
  form.reset();
});


Dê id="form-contato" ao form e name a cada campo (nome, email, mensagem). O site não tem servidor, então a "resposta" é só na tela; mais tarde, com Laravel, ela vira um e-mail de verdade.

  3. Vercel (o mesmo do site da turma): com conta no GitHub, importe o repositório em vercel.com/new e cada atualização no GitHub publica sozinha.
