Uma função é um bloco de código com nome: você escreve uma vez (declara) e usa quantas vezes quiser (chama). Pense numa receita de bolo. Declarar não executa nada: só roda quando você chama com ().

  
Experimente: apague as duas chamadas saudar(); e execute: nada aparece!







  
Parâmetro é o nome que a função usa para a informação que recebe (nome). Argumento é o valor que você manda na chamada ("Ana"). Com vários parâmetros, a ordem importa.

  
Experimente: chame saudar com o seu nome e inverta a ordem em apresentar(20, "Bia").







  
Com return, a função devolve um resultado para quem chamou. Esse valor pode ser guardado numa variável, usado numa conta ou mostrado depois.

  
Experimente: crie const total = somar(somar(1, 2), 3) e mostre o total.







  
console.log só mostra na tela; a função devolve undefined. return devolve o valor, mas não mostra nada sozinho. Quer as duas coisas? Use return na função e console.log na chamada.

  
Experimente: tente fazer x + 1 e y + 1. Qual funciona?







  
Assim que o JavaScript encontra um return, a função termina. Nada depois dele roda. Isso permite usar vários return com if.

  
Experimente: teste situacao com as notas 10, 5 e 0.

Declaração (function nome()), expressão (função anônima numa variável), arrow (=>) e callback (função entregue a outra função). No PHP: function nome(), $f = function(), fn() => e array_map(fn...).

A declaração pode ser chamada antes de aparecer no código (o JavaScript "levanta" ela para o topo: hoisting). Expressão e arrow function não: só existem depois da linha onde foram criadas.

No PHP existe function somar(int $a, int $b): int. O JavaScript não confere tipos: somar("2", 3) vira "23" sem reclamar. Para chegar perto: comentário JSDoc (o VS Code mostra a dica), conferir com typeof dentro da função ou usar TypeScript, o "JavaScript com tipos".

🎯 Objetivo: Criar uma função que cumprimenta uma pessoa pelo nome.
O que fazer
  1. Declare function saudar(nome) { ... }.
  2. Dentro, mostre `Olá, ${nome}!`.
  3. Depois da função, chame: saudar("Ana");
Saída esperada
Olá, Ana!

  
Depois de acertar, teste também: Chame de novo com o seu nome.

O que fazer
  1. Declare function dobro(n).
  2. Dentro, use return n * 2; (não use console.log aqui!).
  3. Fora da função, mostre console.log(dobro(7));

14
