Uma tabela é feita de linhas (<tr>, table row) e, dentro de cada linha, as células: <th> para cabeçalho (fica em negrito e centralizado) e <td> para dados. Sem CSS ela não tem bordas; aqui usamos o atributo border só para enxergar.

  
Experimente: adicione uma linha com o seu nome.







  
Para organizar, o cabeçalho vai em <thead> e os dados em <tbody>. <caption> é o título da tabela. Isso ajuda leitores de tela e facilita o CSS depois.

  
Experimente: adicione um <tfoot> com a média.







  
colspan="2" faz uma célula ocupar duas colunas; rowspan="2", duas linhas. Quando uma célula se estende, as outras daquela linha precisam ser removidas para a conta fechar.

  
Experimente: mude o colspan para 3 e veja o que quebra.







  
<form> agrupa os campos. <input> é um campo de uma linha (tag vazia) e <textarea> de várias. placeholder é a dica cinza dentro do campo e name é como o dado será identificado ao enviar.

  
Experimente: adicione um input para o sobrenome.







  
<label> é o rótulo do campo. Ligue os dois com for (no label) e id (no campo): aí clicar no texto foca o campo, e leitores de tela sabem o que é cada coisa. Ou coloque o input dentro do label.

  
Experimente: clique na palavra "E-mail" na prévia e veja o cursor ir para o campo.







  
O atributo type muda o campo: email, number, password, date, color, range, checkbox (vários podem ser marcados) e radio (só um do mesmo name).

  
Experimente: teste cada campo na prévia; adicione um type="time".







  
<select> é a lista suspensa; cada <option> tem um value (o que é enviado) e o texto (o que aparece). <button type="submit"> envia, type="reset" limpa e type="button" não faz nada sozinho (é para o JavaScript).

  
Experimente: adicione uma option "Laravel" e deixe ela selected.







  
required obriga a preencher; min, max, minlength e type="email" conferem o formato. Se algo falhar, o navegador mostra o balão e não envia. Clique em Enviar com tudo vazio na prévia.

  
Experimente: digite um e-mail sem @ e tente enviar.







  
<fieldset> agrupa campos relacionados numa caixa e <legend> dá o título do grupo. Ótimo para separar "Dados pessoais" de "Endereço".

  
Experimente: crie um segundo fieldset "Endereço".







  
Uma tabela e um formulário para testar.

  
Dica: o atributo border na tabela é só para enxergar; o visual de verdade vem com CSS.







  
🎯 Objetivo: Criar uma tabela com cabeçalho e duas linhas de dados.
O que fazer
  1. Uma <table border="1">.
  2. Primeira linha com <th>: Aluno e Nota.
  3. Depois duas linhas com <td>: Ana/9 e Bia/8.
Resultado esperado
Aluno | Nota
Ana   | 9
Bia   | 8

  
Depois de acertar, teste também: Adicione uma terceira coluna "Situação".








  
🎯 Objetivo: Usar caption, thead e tbody.
O que fazer
  1. <caption> Cardápio.
  2. <thead> com Prato e Preço.
  3. <tbody> com Pizza/R$ 40 e Suco/R$ 8.
Resultado esperado
Cardápio
Prato | Preço
Pizza | R$ 40
Suco  | R$ 8

  
Depois de acertar, teste também: Adicione um <tfoot> com o total.








  
🎯 Objetivo: Fazer um título que ocupa as duas colunas da tabela.
O que fazer
  1. Na primeira linha, um único <th colspan="2"> com Turma de sábado.
  2. Abaixo, uma linha com Ana e Presente.
Resultado esperado
|  Turma de sábado  |
| Ana   | Presente  |

  
Depois de acertar, teste também: Faça uma célula com rowspan="2".








  
🎯 Objetivo: Criar um formulário com nome, mensagem e botão.
O que fazer
  1. Um <form>.
  2. Um <input type="text" name="nome"> com placeholder Seu nome.
  3. Um <textarea name="mensagem">.
  4. Um <button type="submit"> com Enviar.
Resultado esperado
Campo de nome, área de texto e botão Enviar

  
Depois de acertar, teste também: Adicione um campo de e-mail.








  
🎯 Objetivo: Dar rótulos acessíveis aos campos com for e id.
O que fazer
  1. <label for="email">E-mail</label> e <input type="email" id="email" name="email">.
  2. <label for="senha">Senha</label> e <input type="password" id="senha" name="senha">.
Resultado esperado
Clicar em "E-mail" foca o campo de e-mail

  
Depois de acertar, teste também: Faça o mesmo colocando o input dentro do label, sem for/id.








  
🎯 Objetivo: Usar o tipo de input adequado para cada dado.
O que fazer
  1. Idade: type="number", name idade, min="1".
  2. Data de nascimento: type="date", name nascimento.
  3. Aceite: type="checkbox", name aceite.
Resultado esperado
Campo numérico, calendário e caixa de marcar

  
Depois de acertar, teste também: Adicione um type="color" e um type="range".








  
🎯 Objetivo: Montar uma escolha única com radio e uma lista suspensa.
O que fazer
  1. Dois radios com name="turno": value manha (Manhã) e noite (Noite), cada um num label.
  2. Um <select name="curso"> com options html, js e php.
Resultado esperado
Só um turno marcável por vez; lista com 3 cursos

  
Depois de acertar, teste também: Deixe "js" selecionado por padrão.








  
🎯 Objetivo: Um formulário completo com validação do navegador e grupos.
O que fazer
  1. Um <fieldset> com <legend>Dados</legend>: nome (required, minlength="3") e e-mail (type="email", required), com labels ligados por for/id.
  2. Outro <fieldset> Curso: um select curso e um checkbox termos com required.
  3. Botões submit (Matricular) e reset (Limpar).
Resultado esperado
Dois grupos com título, campos obrigatórios que barram o envio vazio, dois botões

  
Depois de acertar, teste também: Tente enviar vazio na prévia e leia os balões.
