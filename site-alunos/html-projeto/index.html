O projeto: ao fim do módulo de HTML você sai com o seu site pessoal (portfólio): quem você é, o que sabe fazer, seus projetos e como falar com você. É um site de verdade, que você vai publicar na internet e colocar no LinkedIn. No módulo de CSS ele ganha visual; no de JavaScript, interação.


Como funciona: escreva o HTML no editor; a prévia mostra o site e o checklist à direita marca cada requisito cumprido quando você clica em ▶ Atualizar. Seu trabalho fica salvo neste navegador. Use o seu nome e os seus dados: o conteúdo é seu, o checklist só confere a estrutura.


Nesta etapa: complete o <head> com <meta name="viewport" content="width=device-width, initial-scale=1">, uma <meta name="description" content="..."> e um <title> com o seu nome (ex.: Ana Souza · Portfólio).











  
O <header> é o cartão de visitas: o seu nome em <h1>, um <p> com a sua apresentação em uma linha (ex.: Desenvolvedor em formação · Recife) e o menu em <nav>.


<header>
  <h1>Seu Nome</h1>
  <p>Sua frase de apresentação</p>
  <nav>
    <ul>
      <li><a href="#sobre">Sobre</a></li>
      ...
    </ul>
  </nav>
</header>


O menu tem quatro links internos: #sobre, #habilidades, #projetos e #contato. Eles só funcionam quando as seções com esses ids existirem (etapas 3 a 6).










  
Uma <section id="sobre"> com um <h2> ("Sobre mim"), dois parágrafos contando quem você é, o que está estudando e o que busca, e uma foto com alt.


Se ainda não tem uma foto hospedada, use src="/img/greenn.svg" por enquanto (quando publicar, troque pela sua: coloque o arquivo na mesma pasta e use src="foto.jpg"). Dica: width="120" para não ficar gigante.









  
Uma <section id="habilidades"> com <h2> e uma lista (<ul>) com pelo menos 3 itens: HTML, CSS, JavaScript, Git, inglês, atendimento ao cliente… tudo o que conta. Dica: use <strong> na parte principal de cada item, ex.: <li><strong>HTML</strong> semântico</li>.








  
Uma <section id="projetos"> com <h2> e pelo menos dois <article>, um para cada projeto. Cada article tem um <h3> (nome do projeto), um <p> (o que é e o que você usou) e um link.


Não tem projetos ainda? Use os exercícios do curso: "Site da escola (HTML)", "Calculadora de média (JavaScript)", "Lista de tarefas (DOM)". Os links podem apontar para o GitHub (target="_blank" para abrir em nova aba).









  
Uma <section id="contato"> com <h2> e um <form>: nome (text), e-mail (type="email" required), mensagem (<textarea>) e um botão type="submit". Cada campo com <label for="id"> ligado pelo id.


<label for="email">E-mail</label>
<input type="email" id="email" name="email" required>


Por enquanto o formulário só tem a estrutura; no módulo de JavaScript ele vai validar e responder.










  
Um <footer> com o ©, o ano e o seu nome, e links para as suas redes (LinkedIn, GitHub, Instagram profissional). Depois, revise: as quatro seções ficam dentro do <main>, os links do menu rolam até cada seção (clique neles na prévia), e a verificação não mostra avisos.


Leia o site inteiro como se fosse um recrutador: está claro quem você é e como te contatar? Se sim, está pronto para o CSS.









  
Seu site é só arquivos: qualquer serviço de hospedagem estática publica de graça. Baixe os arquivos (botão ⬇ Baixar) e escolha um caminho:


    

  1. Netlify Drop (o mais fácil, sem conta): abra app.netlify.com/drop e arraste a pasta do projeto para a página. Em segundos você recebe um link algo.netlify.app. Para manter o link, crie a conta gratuita.
    2. 

  2. GitHub Pages (o jeito profissional): crie uma conta no GitHub, um repositório chamado seu-usuario.github.io, envie os arquivos (botão "Add file → Upload files") e o site fica em https://seu-usuario.github.io. De quebra, o repositório vira o seu portfólio de código.
    3. 

  3. Vercel (o mesmo do site da turma): com conta no GitHub, importe o repositório em vercel.com/new e cada atualização no GitHub publica sozinha.
    4. 



Depois de publicar: coloque o link no seu LinkedIn e no currículo. Esse site é seu: continue melhorando a cada módulo.
