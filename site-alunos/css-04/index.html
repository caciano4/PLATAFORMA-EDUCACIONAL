px é fixo. % é relativo ao pai. rem é relativo ao tamanho de fonte da raiz (16px por padrão: 2rem = 32px), e é a unidade preferida para fontes e espaços, porque acompanha a configuração de acessibilidade do usuário. vw/vh são % da largura/altura da tela: 100vh é a tela inteira.

  
Experimente: mude o font-size do html para 20px e veja tudo que usa rem crescer junto.








  
@media (max-width: 500px) { ... } aplica as regras de dentro só quando a tela tem até 500px: é assim que o mesmo site fica diferente no celular. A largura em que o layout muda é o breakpoint. Num site de verdade, isso só funciona com o <meta name="viewport"> no head (aula H4).

  
Experimente: estreite e alargue a janela do navegador: a prévia muda de cor no breakpoint. Depois mude 500px para 900px.








  
O layout responsivo mais comum: no computador, colunas lado a lado com flex; no celular, flex-direction: column empilha. A regra de dentro da media query vence a de fora porque vem depois (é o cascading do nome CSS).

  
Experimente: estreite a janela até as colunas empilharem. Depois troque column por column-reverse.








  
O jeito recomendado é o contrário: escrever primeiro o CSS do celular (simples, uma coluna) e usar @media (min-width: 700px) para adicionar colunas nas telas maiores. Dá menos código e o celular, que é a maioria dos acessos, carrega o CSS mais simples.

  
Experimente: adicione mais um breakpoint: @media (min-width: 1000px) com 4 colunas.








  
Duas receitas de todo site: img { max-width: 100%; height: auto; } faz a imagem nunca estourar a largura do pai. E para o menu: no celular, esconder os links (display: none) e mostrar o botão ☰ (que o JavaScript abre); no computador, o contrário.

  
Experimente: estreite a janela e veja o menu virar ☰. Mude o breakpoint para 300px.








  
transition: propriedade duração faz a mudança de estado ser suave em vez de instantânea. Com transform: scale(1.05) o botão cresce ao passar o mouse; translateY(-4px) levanta o cartão; cursor: pointer mostra a mãozinha. Pequeno detalhe, enorme diferença de sensação.

  
Experimente: mude 0.3s para 2s, e troque scale(1.05) por rotate(3deg).








  
position: absolute tira o elemento do fluxo e o posiciona com top, right, bottom, left em relação ao ancestral mais próximo que tenha position (por isso o pai leva position: relative). É o jeito de pôr um selo no canto de um cartão, um badge num ícone, um botão de fechar num modal.

  
Experimente: apague o position: relative do .card e veja o selo fugir para o canto da página.








  
position: fixed prende o elemento na tela: não sai do lugar quando a página rola (botão de WhatsApp no canto). position: sticky rola normalmente até encostar no top indicado, e aí gruda (cabeçalhos que ficam visíveis). z-index decide quem fica por cima.

  
Experimente: role a prévia. Depois troque sticky por static e role de novo.








  
Declare valores uma vez em :root (--nome: valor) e use com var(--nome). Trocar a cor do site inteiro vira mudar uma linha. É assim que se faz tema claro/escuro: redefinir as variáveis dentro de uma classe ou media query.

  
Experimente: mude --principal para #16A34A e veja tudo acompanhar.








  
O site que você montou na última aula de HTML, agora com visual: variáveis, container centralizado, header flex, cards em grid, hover com transição e media query para o celular. Leia o CSS de cima para baixo: você conhece cada linha.

  
Experimente: estreite a janela para ver a versão celular. Depois troque a paleta nas variáveis.








  
A mesma página do site completo, com o CSS zerado: estilize do seu jeito.

  
Dica: comece pelas variáveis e pelo body; depois header, cards e, por último, a media query.








  
🎯 Objetivo: Usar unidades relativas.
O que fazer
  1. h1 com font-size: 2rem;.
  2. .caixa com width: 50%;.
Resultado esperado
Título com 32px (2 × 16) e a caixa com metade da largura

  
Depois de acertar, teste também: Adicione html { font-size: 20px; } e veja o título crescer para 40px.









  
🎯 Objetivo: Escrever sua primeira media query.
O que fazer
  1. .aviso com background-color: #38BDF8; e padding: 30px;.
  2. Uma @media (max-width: 500px) em que .aviso tem background-color: #F97316;.
Resultado esperado
Azul em telas largas; laranja quando a janela tem até 500px

  
Depois de acertar, teste também: Estreite a janela do navegador para ver a troca. Depois mude o breakpoint para 800px.









  
🎯 Objetivo: Fazer um layout de colunas virar pilha no celular.
O que fazer
  1. .colunas com display: flex; e gap: 12px;; .colunas .caixa com flex: 1;.
  2. Em @media (max-width: 500px), .colunas com flex-direction: column;.
Resultado esperado
Três colunas iguais; abaixo de 500px, uma embaixo da outra

  
Depois de acertar, teste também: Estreite a janela para ver. Depois use column-reverse.









  
🎯 Objetivo: Começar pelo celular e adicionar colunas nas telas grandes.
O que fazer
  1. .cards com display: grid;, grid-template-columns: 1fr; e gap: 12px;.
  2. Em @media (min-width: 700px), .cards com grid-template-columns: repeat(3, 1fr);.
Resultado esperado
Uma coluna; a partir de 700px de largura, três

  
Depois de acertar, teste também: Adicione um @media (min-width: 1000px) com 4 colunas.









  
🎯 Objetivo: Dar resposta suave ao hover.
O que fazer
  1. .botao: background-color: #0EA5E9;, color: white;, padding: 12px 24px;, border: 0;, border-radius: 8px;, cursor: pointer; e transition: background-color 0.3s;.
  2. .botao:hover: background-color: #F97316;.
Resultado esperado
Botão azul que vira laranja suavemente ao passar o mouse

  
Depois de acertar, teste também: Adicione transform: scale(1.1) no hover (e transform 0.3s na transition).









  
🎯 Objetivo: Posicionar um elemento em relação ao pai.
O que fazer
  1. .card com position: relative;, padding: 20px; e border: 1px solid #CBD5E1;.
  2. .selo com position: absolute;, top: 10px;, right: 10px;, background-color: #F97316;, color: white; e padding: 4px 10px;.
Resultado esperado
O selo "NOVO" colado no canto superior direito do cartão

  
Depois de acertar, teste também: Troque right: 10px por left: 10px.









  
🎯 Objetivo: Centralizar as cores do site em variáveis.
O que fazer
  1. Em :root: --principal: #38BDF8; e --escuro: #15171E;.
  2. .topo com background-color: var(--escuro); e color: var(--principal);.
  3. h1 com color: var(--principal);.
Resultado esperado
Barra escura com texto azul e título azul, tudo vindo das variáveis

  
Depois de acertar, teste também: Mude --principal para #16A34A: barra e título mudam juntos.









  
🎯 Objetivo: Juntar tudo: container, header flex, cards em grid, hover e media query.
O que fazer
  1. * { box-sizing: border-box; }; body com margin: 0;, font-family: Arial, sans-serif; e background-color: #F1F5F9;.
  2. .container com max-width: 900px;, margin: 0 auto; e padding: 0 20px;.
  3. .topo com background-color: #15171E;; .barra com display: flex;, justify-content: space-between;, align-items: center; e height: 60px;; .logo com color: #F0C23B;; .menu a com color: white;, text-decoration: none; e margin-left: 20px;.
  4. .cards com display: grid;, grid-template-columns: 1fr; e gap: 16px;; .card com background-color: white;, padding: 20px;, border-radius: 12px; e transition: transform 0.2s;; .card:hover com transform: translateY(-4px);.
  5. @media (min-width: 700px): .cards com grid-template-columns: repeat(3, 1fr);.
Resultado esperado
Header escuro com logo e menu nas pontas, conteúdo centralizado, cards brancos que levantam no hover; três colunas a partir de 700px

  
Depois de acertar, teste também: Estreite a janela para ver a versão celular. Depois troque as cores por variáveis em :root.
