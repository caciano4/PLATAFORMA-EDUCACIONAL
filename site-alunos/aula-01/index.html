Uma variável é uma caixa com etiqueta: a etiqueta é o nome e dentro fica um valor. Você cria a caixa uma vez e depois usa o nome para ler ou trocar o que tem dentro. let deixa trocar o valor; const não deixa.

  
Experimente: tente fazer escola = "Outra" e veja o erro.







  
Regra da casa: use const por padrão e let quando o valor precisar mudar. O var é a forma antiga: ele ignora os blocos { } e causa bugs. Você vai ver em código antigo, mas não use.

  
Experimente: troque o var por let e veja a última linha dar erro (o certo!).







  
Os tipos básicos (primitivos) são string, number, boolean, undefined e null. Além deles, object (objetos e arrays). typeof diz o tipo de um valor. Pegadinhas: typeof null é "object" e array também é "object" (use Array.isArray).

  
Experimente: descubra o tipo de "10" e de 10.







  
Nomes: em camelCase (notaFinal), sem espaço, sem começar com número, sem acento. Atenção: const impede trocar a caixa, mas não impede mexer no que tem dentro de um array ou objeto.

  
Experimente: tente frutas = []. Por que dá erro, se o push funcionou?







  
Um objeto agrupa informações sobre uma coisa em pares chave: valor. Array é uma lista em ordem (acessa por índice); objeto é uma ficha com campos nomeados (acessa pelo nome). Acesse com ponto (aluno.nome) ou colchetes (aluno["nome"]).

  
Experimente: acesse uma propriedade que não existe, como aluno.email.







  
Atribuir numa chave que existe altera; numa chave nova adiciona; delete remove. Colchetes servem quando o nome da chave está numa variável.

  
Experimente: troque campo para "cidade".







  
Uma propriedade pode guardar uma função: aí ela vira um método (como o console.log e o frutas.push que você já usa!). Dentro do método, this é o próprio objeto.

  
Experimente: crie um método sacar(valor) que não deixa o saldo ficar negativo.







  
Object.keys devolve as chaves, Object.values os valores e Object.entries os pares. Com for...in você passa por cada chave.

  
Experimente: use Object.values com um for...of.







  
Na vida real os dados chegam assim: um array onde cada item é um objeto (uma lista de alunos, de produtos, de pedidos). Juntamos tudo o que já vimos: índice, laço e ponto.

  
Experimente: adicione um aluno com push e mostre a lista de novo.







  
map passa por todos os itens e devolve um array novo com o resultado de cada um. O original não muda. Mesmo tamanho na entrada e na saída.

  
Experimente: faça um map que devolve `${a.nome} (${a.nota})`.







  
filter devolve um array novo só com os itens em que a função devolve true. Pode sair menor que o original.

  
Experimente: filtre os reprovados (nota menor que 7).







  
find devolve o primeiro item que combina (ou undefined). some responde "algum combina?" e every, "todos combinam?". Os dois devolvem true ou false.

  
Experimente: procure um aluno que não existe com find.







  
reduce percorre a lista acumulando um resultado: uma soma, um total, um maior valor. Recebe a função (acumulador, item) => ... e o valor inicial do acumulador.

  
Experimente: calcule a média das notas (soma / length).







  
includes diz se um valor está na lista; join junta os itens num texto; sort ordena (cuidado: ele muda o array original). Como map e filter devolvem arrays, dá para encadear.

  
Experimente: ordene do maior para o menor trocando a.nota - b.nota por b.nota - a.nota.







  
Um jeito curto de tirar valores de dentro de um objeto ou array e colocar em variáveis. No objeto vale o nome da chave; no array vale a posição.

  
Experimente: desestruture também a cidade.







  
Os ... "espalham" os itens. Servem para copiar um array ou objeto (sem mexer no original), juntar listas e criar uma cópia trocando só alguns campos.

  
Experimente: faça const mesmo = lista (sem spread), dê push e veja o original mudar também.







  
JSON é o formato de texto usado para guardar e enviar dados (é assim que uma API responde). JSON.stringify transforma objeto em texto; JSON.parse faz o caminho de volta. Vamos usar muito na aula de assíncrono.

  
Experimente: use JSON.stringify(aluno, null, 2) para um texto mais legível.







  
?. (encadeamento opcional) lê uma propriedade só se o que vem antes existir; se não, devolve undefined em vez de dar erro. ?? dá um valor padrão quando o valor é null ou undefined.

  
Experimente: troque ?. por . na primeira linha e veja o erro.
