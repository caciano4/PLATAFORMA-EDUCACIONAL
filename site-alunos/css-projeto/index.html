O projeto: o portfólio que você estruturou no módulo de HTML ganha agora o visual: cores, fontes, cartões, menu e versão para celular. Se você fez o projeto de HTML neste navegador, o seu index.html já está na aba ao lado; se não, você recebe um portfólio-modelo para estilizar (troque os textos pelos seus).


Como funciona: escreva na aba style.css; a prévia é o site de verdade; o checklist confere o estilo aplicado (cor, tamanho, display…) quando você clica em ▶ Atualizar. Você pode editar o HTML também (para adicionar uma classe, por exemplo). No fim, baixe o .zip e publique.


Nesta etapa: as variáveis da sua paleta em :root (--principal, --escuro, --fundo, --texto), * { box-sizing: border-box; } e o body com margin: 0, font-family, background-color, color e line-height: 1.6. Dica: escolha 2 cores que combinem (coolors.co ajuda) e use var(--principal) em tudo que for destaque.










  
O header com fundo escuro (var(--escuro)), texto claro, padding e text-align: center (ou um layout flex com o nome de um lado e o menu do outro, como na aula C3). O nav ul vira uma linha: display: flex, gap, list-style: none, margin: 0 e padding: 0. Os links sem sublinhado, com a cor de destaque no :hover e uma transition.


header { background-color: var(--escuro); color: white; padding: 40px 20px; text-align: center; }
nav ul { display: flex; justify-content: center; gap: 24px; list-style: none; margin: 0; padding: 0; }
nav a { color: white; text-decoration: none; transition: color 0.2s; }
nav a:hover { color: var(--principal); }










  
O conteúdo não pode esticar até as bordas em telas grandes: envolva as seções com um container (o main ou uma div) com max-width: 900px, margin: 0 auto e padding: 0 20px. Cada section ganha padding: 40px 0; os h2 ficam na cor escura; a foto fica redonda com border-radius: 50% e nunca estoura a largura (img { max-width: 100%; height: auto; }).


main { max-width: 900px; margin: 0 auto; padding: 0 20px; }
section { padding: 40px 0; }
#sobre img { border-radius: 50%; }










  
Cada article vira um cartão: fundo branco, padding: 20px, border-radius: 12px, uma box-shadow leve e transition com um :hover que levanta (transform: translateY(-4px)). O pai dos articles vira display: grid com gap; por enquanto uma coluna (celular primeiro): a media query da etapa 6 faz as colunas.


#projetos .cards { display: grid; grid-template-columns: 1fr; gap: 16px; }
article { background-color: white; padding: 20px; border-radius: 12px; box-shadow: 0 2px 8px rgba(0,0,0,.08); transition: transform .2s; }
article:hover { transform: translateY(-4px); }


Se o seu HTML não tem uma div envolvendo os articles, adicione uma na aba index.html (ex.: <div class="cards">) ou use a própria section como grid.










  
Campos que ocupam a largura toda, com padding, borda fina e cantos arredondados; label em bloco acima de cada campo; o botão com a cor de destaque, sem borda, com cursor: pointer.


form label { display: block; margin-top: 12px; font-weight: bold; }
form input, form textarea { width: 100%; padding: 10px; border: 1px solid #CBD5E1; border-radius: 8px; font: inherit; }
form button { margin-top: 16px; padding: 12px 28px; background-color: var(--principal); border: 0; border-radius: 8px; font-weight: bold; cursor: pointer; }










  
Estreite a janela do navegador: o site precisa funcionar no celular. A regra é mobile first: o CSS que você escreveu é o do celular (uma coluna); agora uma @media (min-width: 700px) coloca os cartões em 3 colunas (ou 2) e, se quiser, aumenta o h1.


@media (min-width: 700px) {
  #projetos .cards { grid-template-columns: repeat(3, 1fr); }
  header h1 { font-size: 3rem; }
}


Teste: com a janela estreita, nada pode sair para o lado (sem barra de rolagem horizontal).









  
O footer com o mesmo fundo escuro do header, texto centralizado e cor suave; os links do rodapé na cor de destaque. Depois, revise o site inteiro em três larguras (celular, tablet, computador) e confira o contraste: texto claro em fundo escuro, texto escuro em fundo claro.


Quando tudo estiver ✓, clique em ⬇ Baixar: você recebe meu-portfolio.zip com index.html e style.css ligados pelo <link>. Abra o index.html no seu computador para conferir.









  
Seu site é só arquivos: qualquer serviço de hospedagem estática publica de graça. Baixe os arquivos (botão ⬇ Baixar) e escolha um caminho:


    

  1. Netlify Drop (o mais fácil, sem conta): abra app.netlify.com/drop e arraste a pasta do projeto para a página. Em segundos você recebe um link algo.netlify.app. Para manter o link, crie a conta gratuita.
    2. 

  2. GitHub Pages (o jeito profissional): crie uma conta no GitHub, um repositório chamado seu-usuario.github.io, envie os arquivos (botão "Add file → Upload files") e o site fica em https://seu-usuario.github.io. De quebra, o repositório vira o seu portfólio de código.
    3. 

  3. Vercel (o mesmo do site da turma): com conta no GitHub, importe o repositório em vercel.com/new e cada atualização no GitHub publica sozinha.
    4. 



Depois de publicar: coloque o link no seu LinkedIn e no currículo. Esse site é seu: continue melhorando a cada módulo.
