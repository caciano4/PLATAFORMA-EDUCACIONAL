O DOM é a forma como o navegador representa a página: ele lê o HTML e cria objetos que o JavaScript pode ler e alterar. Tudo começa pelo objeto document. A prévia ao lado é a página de verdade, e o seu código roda dentro dela.

  
Experimente: troque o document.title e mostre document.body no console.








  
Busca um único elemento pelo id, escrito sem o #. Se o id não existir, devolve null.

  
Experimente: busque um id que não existe e tente pegar o textContent dele. Qual erro aparece?








  
getElementsByClassName (sem o ponto) e getElementsByTagName (sem < >) devolvem uma HTMLCollection: acessa por índice, mas não tem forEach. Para usar forEach, converta com Array.from().

  
Experimente: use getElementsByTagName("li") e mostre quantos são.








  
Aceitam qualquer seletor CSS (#id, .classe, tag). querySelector devolve o primeiro (ou null); querySelectorAll devolve todos numa NodeList, que tem forEach. Regra prática: um elemento → querySelector; vários → querySelectorAll.

  
Experimente: tente document.querySelector(".nao-existe") e querySelectorAll(".nao-existe").length.








  
Se o seletor funciona no CSS, funciona no querySelector: filho direto (ul > li), pseudo-classe (:first-child, :last-child) e atributo ([type='text']).

  
Experimente: pegue o último item com ul > li:last-child.








  
textContent lê/troca só o texto (seguro). innerHTML lê/troca o HTML de dentro (as tags são interpretadas: não use com texto digitado pelo usuário). value é o valor de um input, sempre uma string.

  
Experimente: troque textContent por innerHTML na linha do título e coloque <i>Olá</i>.








  
Liga e desliga classes do CSS sem apagar as outras. toggle: se tem, tira; se não tem, põe. Prefira classList a className = "...", que apaga as outras classes.

  
Experimente: rode várias vezes só a linha do toggle e veja o card mudar.








  
As propriedades são em camelCase (backgroundColor, não background-color) e o valor é sempre texto com unidade ("24px"). Para muitos estilos, prefira criar uma classe e usar classList.

  
Experimente: mude também titulo.style.textAlign = "center".








  
Propriedade é acesso direto no objeto (link.id, input.value). Atributo usa os métodos getAttribute, setAttribute, hasAttribute e removeAttribute. link.href devolve a URL completa; getAttribute("href") devolve o que está escrito no HTML.

  
Experimente: remova o target com removeAttribute e confira com hasAttribute.








  
A partir de um elemento dá para "andar" pela árvore: parentElement (o pai), children (os filhos) e previousElementSibling / nextElementSibling (os irmãos). Nas pontas, o resultado é null.

  
Experimente: mostre bia.nextElementSibling.nextElementSibling.








  
elemento.addEventListener("click", função): a função (um callback!) roda toda vez que o evento acontece. Execute e depois clique no botão da prévia. Outros eventos: input, submit, keydown, mouseover.

  
Experimente: troque "click" por "mouseover" e passe o mouse no botão.








  
Quase todo código de DOM segue 4 passos: 1. selecionar o elemento, 2. acessar o que ele tem, 3. modificar e 4. reagir a um evento. Execute e clique no botão várias vezes.

  
Experimente: faça o título voltar ao texto original quando passar de 5 exclamações.








  
Juntando as aulas anteriores: uma função que cria um item, um array percorrido com forEach e um if para destacar. É assim que os sites montam listas a partir de dados.

  
Experimente: acrescente um aluno no array e mude a regra de destaque.

🎯 Objetivo: Adicionar o item digitado na lista a cada clique, sem aceitar campo vazio.
O que fazer

  2. Se estiver vazio, não faça nada (if (!item.value) return;).
  3. Crie um li com document.createElement("li"), coloque o texto e use compras.appendChild(li) (ou innerHTML +=).
  4. Limpe o campo: item.value = "".
Resultado esperado
Digitou Pão + Adicionar → novo item "Pão"
Campo vazio → nada acontece

  
Depois de acertar, teste também: Faça cada item ser removido ao ser clicado (li.remove()).
