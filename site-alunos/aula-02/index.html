🎯 Objetivo: Descobrir se um número é positivo, negativo ou zero.
O que fazer
  1. Use um if para testar se numero > 0 e mostre "Positivo".
  2. Use um else if para testar se numero < 0 e mostre "Negativo".
  3. Use um else para todo o resto e mostre "Zero".
Saída esperada
Negativo

  
Depois de acertar, teste também: Troque numero para 10 (deve dar Positivo) e para 0 (deve dar Zero).







  
🎯 Objetivo: Mostrar se um número é par ou ímpar, de dois jeitos diferentes.
O que fazer
  1. Com if/else: se numero % 2 === 0, mostre "Par"; senão, mostre "Ímpar".
  2. Agora faça o mesmo em uma linha com o ternário: console.log(condição ? "Par" : "Ímpar").
Saída esperada
Ímpar
Ímpar

  
Depois de acertar, teste também: Troque numero para 8: as duas linhas devem mostrar Par.







  
🎯 Objetivo: Comparar dois números e dizer qual é o maior.
O que fazer
  1. Se a > b, mostre `O maior é ${a}`.
  2. Senão, se b > a, mostre `O maior é ${b}`.
  3. Senão (são iguais), mostre "São iguais".
Saída esperada
O maior é 30

  
Depois de acertar, teste também: Coloque a e b com o mesmo valor: deve aparecer São iguais.







  
🎯 Objetivo: Transformar uma nota de 0 a 10 em conceito.
O que fazer
  1. Nota 9 ou mais: mostre "A".
  2. Nota 7 ou mais: mostre "B".
  3. Nota 5 ou mais: mostre "C".
  4. Abaixo de 5: mostre "Reprovado". Comece pela maior nota: a ordem importa!
Saída esperada
B

  
Depois de acertar, teste também: Teste com 9.5 (A), 5 (C) e 3 (Reprovado).







  
🎯 Objetivo: Decidir a situação do aluno olhando nota e frequência ao mesmo tempo.
O que fazer
  1. Aprovado: nota >= 7 && frequencia >= 75.
  2. Recuperação: nota >= 5 && frequencia >= 75.
  3. Reprovado: qualquer outro caso (use else).
Saída esperada
Recuperação

  
Depois de acertar, teste também: Com nota = 9 e frequencia = 50 o resultado deve ser Reprovado (faltou demais!).







  
🎯 Objetivo: Calcular o preço do ingresso pela idade.
O que fazer
  1. Crie let valor; para guardar o preço.
  2. Até 12 anos ou 60 anos ou mais: valor = 15. Dica: dá para juntar as duas condições com ||.
  3. Senão: valor = 30.
  4. Mostre `Valor do ingresso: R$ ${valor}`.

🎯 Objetivo: Calcular o total da compra com ou sem frete.
O que fazer
  1. O frete é grátis (0) se valorCompra > 200 ou se ehAssinante for true.
  2. Caso contrário, o frete é 25. Tente usar o ternário: const frete = condição ? 0 : 25;
  3. Mostre `Total a pagar: R$ ${valorCompra + frete}`.
Saída esperada
Total a pagar: R$ 175

  
Depois de acertar, teste também: Troque ehAssinante para true: o total deve cair para R$ 150.

🎯 Objetivo: Somar todos os números de 1 até 100 usando while.
O que fazer
  1. Repita enquanto numeroAtual <= 100.
  2. A cada volta: soma += numeroAtual; e depois numeroAtual++;
  3. Depois do loop, mostre `A soma é ${soma}`.
  4. Bônus: crie somaPares e, com um if dentro do while, some só os pares (resultado: 2550).
Saída esperada
A soma é 5050

  
Depois de acertar, teste também: Troque o limite para 10: a soma deve dar 55.
