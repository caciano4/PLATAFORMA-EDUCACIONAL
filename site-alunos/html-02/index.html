<ul> (unordered list) é uma lista com bolinhas; cada item é um <li>. Os <li> só podem ficar dentro de uma lista.

  
Experimente: adicione mais dois itens.







  
<ol> (ordered list) numera os itens sozinha: se você trocar a ordem, os números se ajustam. Com start="5" ela começa de outro número e com type="a" usa letras.

  
Experimente: troque para type="A" e depois type="I".







  
Uma lista pode ficar dentro de um <li>: é assim que se faz menus com submenus e sumários. Cuidado com a indentação para não se perder nas tags.

  
Experimente: adicione um sub-item em CSS.







  
Um atributo fica dentro da tag de abertura, no formato nome="valor". Ele configura o elemento: para onde o link vai, qual imagem mostrar, qual o idioma. Já usamos lang e charset no esqueleto.

  
Experimente: mude o title e passe o mouse em cima do texto.







  
<a> (âncora) cria um link. O atributo href diz para onde ir. O texto entre as tags é o que a pessoa clica. Na prévia os links não navegam de verdade, mas o navegador real vai.

  
Experimente: aponte o link para o site da sua escola.







  
target="_blank" abre em nova aba. href="mailto:..." abre o e-mail. E um href="#id" rola a página até o elemento com aquele id (o sumário de uma página longa).

  
Experimente: clique em "Ir para o fim" na prévia.







  
<img> é uma tag vazia (não fecha). src é o caminho da imagem e alt é o texto alternativo: aparece se a imagem não carregar e é lido pelos leitores de tela. Sempre escreva o alt.

  
Experimente: erre o nome do arquivo no src e veja o alt aparecer.







  
width e height definem o tamanho (em pixels). O caminho pode ser relativo (img/foto.jpg, a partir da pasta da página) ou absoluto (https://...). Uma imagem dentro de um <a> vira um link clicável.

  
Experimente: mude o width para 300 e tire o height.







  
<figure> agrupa uma imagem com a sua legenda em <figcaption>. É o jeito certo de colocar fotos em artigos.

  
Experimente: coloque a legenda acima da imagem (o figcaption pode ser o primeiro filho).
