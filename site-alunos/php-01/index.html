PHP é a linguagem do servidor: enquanto o JavaScript roda no navegador de quem visita, o PHP roda na máquina que entrega a página (é ele que monta o HTML, fala com o banco de dados, envia e-mail). O Laravel é um framework escrito em PHP. Aqui o PHP está rodando dentro do seu navegador só para você treinar; a saída é texto, como no console do JavaScript. Todo arquivo PHP começa com <?php; echo mostra algo na tela.

  
Experimente: apague a linha <?php e execute: o PHP devolve o texto do jeito que está (é assim que ele mistura com HTML).







  
Em PHP a variável começa com $ e não precisa de let ou const: é só atribuir. O tipo é decidido pelo valor (string, int, float, bool), igual ao JavaScript. var_dump mostra o valor com o tipo: é o seu typeof. E toda instrução termina com ; obrigatório.

  
Experimente: troque $idade = 20 por $idade = "20" e veja o var_dump mudar de int para string.







  
var_dump é do PHP puro e fica feio com arrays grandes. No Laravel, o que todo mundo usa para depurar é o dd() (dump and die): mostra o valor bonito e para a execução ali; e o dump(), que mostra e continua. Já deixamos os dois prontos neste playground. Você vai usar o dd o tempo todo: para ver o que chegou de um formulário, o que veio do banco, o que uma função devolveu.

  
Experimente: troque o dd por dump e veja a última linha aparecer. Depois coloque um dd($aluno["notas"]) logo no começo.







  
Para juntar textos o PHP usa o ponto (.), não o +. Entre aspas duplas, variáveis são substituídas ("Olá, $nome"), como o template string do JS; entre aspas simples, não. Funções úteis: strlen, strtoupper, strtolower, ucfirst, str_replace, trim.

  
Experimente: troque as aspas duplas da linha do Olá por aspas simples e veja o $nome aparecer literalmente.







  
Os operadores são os mesmos do JavaScript: + - * / % e **. A divisão devolve float quando não é exata; intdiv faz a divisão inteira. round, floor, ceil arredondam. number_format formata dinheiro do jeito brasileiro: number_format($v, 2, ',', '.').

  
Experimente: calcule 10% de desconto em cima do total e mostre com number_format.







  
Igual ao JavaScript, com uma diferença de grafia: elseif é uma palavra só. Comparações: == (valor), === (valor e tipo), !=, <, >=. Lógicos: &&, ||, ! (também existem and e or). Existe o ternário $cond ? a : b e o match, um switch moderno.

  
Experimente: mude a média para 4.5 e para 9. Depois troque == por === na comparação "7" == 7.







  
O array do PHP é criado com [ ] como no JS. count é o length; $lista[] = x é o push; foreach ($lista as $item) é o for...of. Outras: in_array (includes), implode (join), explode (split), sort, array_sum.

  
Experimente: adicione sort($frutas); antes do foreach e veja a ordem mudar.







  
O que no JavaScript é um objeto { nome: "Ana" }, no PHP é um array associativo: ["nome" => "Ana"]. Acessa com $aluno["nome"]. No foreach, as $chave => $valor entrega os dois. É exatamente o formato que o Laravel usa para passar dados para as views e que vira JSON nas APIs.

  
Experimente: adicione a chave "cidade" ao aluno e mostre no foreach.







  
Os laços são iguais aos do JavaScript, só com $ nas variáveis. for para contar, while para repetir até uma condição, break para sair, continue para pular. Para percorrer arrays, prefira o foreach.

  
Experimente: faça a tabuada ir até 20, e no while mude para contar de 2 em 2.







  
Declaração igual à do JS, com uma vantagem: o PHP deixa dizer o tipo dos parâmetros e do retorno (function media(array $notas): float), e dá erro se chamar errado. Parâmetros podem ter valor padrão. Também existe a arrow function de uma linha: fn($x) => $x * 2, muito usada com array_map e array_filter (o map e o filter do JS).

  
Experimente: chame saudacao("Ana", "Boa noite") e depois chame media("oi") para ver o erro de tipo.







  
O trabalho de verdade do PHP é montar HTML com dados. Dá para dar echo em tags, ou fechar o PHP com ?>, escrever HTML normal e abrir <?php de novo onde precisa de lógica. Clique em 🌐 ver como página na saída para ver o resultado renderizado. É exatamente isso que o Blade do Laravel faz, só que com uma sintaxe mais limpa.

  
Experimente: adicione um curso ao array e veja a lista crescer. Depois troque <li> por uma tabela.
