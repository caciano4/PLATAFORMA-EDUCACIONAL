# HTML: tabelas e formulários

**Módulo:** HTML · aula 3 de 4
**Playground dos alunos:** https://site-alunos-nu.vercel.app/html-03/
**Apostila:** `apostila-html-03.pdf` (também para download no site)
**Duração:** 2h

O playground de HTML é diferente dos de JavaScript: o aluno escreve o **HTML** de um lado e vê a **página renderizada** do outro. A verificação aponta tags sem fechar ou fora de ordem, e os exercícios são corrigidos lendo a página montada (tags, textos e atributos).

## Exercícios

| # | Exercício | Objetivo |
|---|---|---|
| 01 | Tabela de notas | Criar uma tabela com cabeçalho e duas linhas de dados. |
| 02 | Tabela organizada | Usar caption, thead e tbody. |
| 03 | Célula mesclada | Fazer um título que ocupa as duas colunas da tabela. |
| 04 | Formulário de contato | Criar um formulário com nome, mensagem e botão. |
| 05 | Labels ligados | Dar rótulos acessíveis aos campos com for e id. |
| 06 | Tipos certos | Usar o tipo de input adequado para cada dado. |
| 07 | Radio e select | Montar uma escolha única com radio e uma lista suspensa. |
| 08 | Desafio: ficha de matrícula | Um formulário completo com validação do navegador e grupos. |
