O bloco entre { } só roda se a condição for true. Se for false, o JavaScript pula o bloco.

  
Experimente: troque a idade para 15 e execute de novo.







  
O else é o plano B. Sempre um dos dois blocos roda, nunca os dois.

  
Experimente: mude o saldo para 100. Qual mensagem aparece agora?







  
O JavaScript testa de cima para baixo e para na primeira condição verdadeira. O else final pega todo o resto.

  
Experimente: teste com as notas 9, 6 e 3.







  
Aqui as condições estão na ordem errada. Quem tirou 9 deveria ser aprovado, mas o JavaScript para na primeira condição verdadeira.

  
Experimente: conserte a ordem das condições para o 9 aparecer como Aprovado.







  
&&: as duas precisam ser true. ||: basta uma ser true. !: inverte o valor.

  
Experimente: troque temCNH para false e dia para "terça".







  
Leia assim: condição ? valor se true : valor se false. Serve para escolher um valor.

  
Experimente: mude numero para 8 e idade para 12.







  
Compara uma variável com vários valores. O default funciona como o "senão".

  
Experimente: teste diaSemana com 1, 3 e 9.







  
Sem o break, depois de achar o case certo o JavaScript continua executando os próximos.

  
Experimente: coloque os break de volta e execute de novo.







  
Só 6 valores contam como false no if: false, 0, "", null, undefined e NaN. Todo o resto é truthy.

  
Experimente: coloque seu nome entre as aspas de nome.







  
O while é um if que se repete: testa a condição e, enquanto for true, roda o bloco e volta a testar.

  
Experimente: faça contar até 10. Depois, faça contar de 2 em 2 (troque contador++ por contador += 2).







  
A condição pode depender de uma conta. Aqui sacamos R$ 30 enquanto houver saldo, e usamos um if dentro do loop.

  
Experimente: mude o saldo inicial para 250 e o valor do saque para 50.







  
Se a condição nunca virar false, o programa não para. Este playground interrompe sozinho depois de 2 segundos (no terminal, use Ctrl + C).

  
Experimente: execute, veja o problema e depois adicione i++ dentro do bloco.
